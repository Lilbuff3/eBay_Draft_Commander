## 2024-05-08 - Icon-Only Button Accessibility in Action Columns
**Learning:** In highly interactive components like `ListingRow`, the "Actions" column frequently utilizes multiple icon-only buttons (e.g., Save, Cancel, Relist, Edit, View). While visually clean and space-efficient, these buttons present a severe accessibility barrier for screen reader users if `aria-label` attributes are omitted. Hover-based tooltips (via `title` attributes) are insufficient as they are not accessible to keyboard-only or screen reader users by default without additional configuration.
**Action:** When creating or reviewing table, data grid, or list item components with trailing "Actions" columns, explicitly mandate the inclusion of `aria-label` attributes on all icon-only buttons. The label must clearly describe the action (e.g., "Relist item") rather than the icon itself (e.g., "Refresh icon"). Ensure this check is part of the standard review process for any UI elements using `size="icon"` properties.
