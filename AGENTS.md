# eBay Draft Commander

## Purpose
AI-powered eBay listing automation platform. Flask backend + React TypeScript PWA frontend. Scans product images from an inbox folder, uses Google Gemini AI for vision analysis and research grounding, maps eBay categories and pricing, then creates listings via the eBay Trading API (AddFixedPriceItem XML). Real-time Socket.IO sync to a mobile-friendly dashboard.

## For AI Agents

### Working In This Directory
- **Read `CLAUDE.md` first** — it is the authoritative architecture reference
- `master` is the default branch — feature branches for isolation, merge and push at end of session
- Backend on port 5000, Vite dev on port 5175 (proxies `/api` → `127.0.0.1:5000`)
- `.env` contains secrets — **never edit directly**, use SettingsManager/API or Settings UI
- `load_dotenv_manually()` walks parent dirs to find `.env` (supports git worktrees)
- Run `npm run build` in `frontend/` before committing frontend changes
- SQLite DB at `data/commander.db` — WAL mode, auto-created on first run

### Testing Requirements
```bash
pytest tests/unit/ -v                # 244+ unit tests (no external deps)
pytest tests/integration/ -v         # Needs .env credentials + eBay sandbox
cd frontend && npm run test          # Vitest frontend tests
```

### Common Patterns
- **Tab-based navigation** — `activeTab` in Zustand store, persisted to localStorage, no react-router
- **Single Zustand store** — `useCommanderStore.ts` manages jobs, queue, settings, UI state
- **Socket.IO real-time** — `job_added`, `job_update`, `job_log` events via `useJobSync` hook
- **Condition priority chain** — user_override > metadata > folder_name > AI-detected > DEFAULT
- **3-phase AI pipeline** — Phase 1: Gemini vision → Phase 2: Google Search grounding → Phase 3: aspect mapping
- **Trading API XML** for all new listings (`AddFixedPriceItem`), Inventory API for management
- **Free shipping** — `ESTIMATED_SHIPPING_COST` ($6.50) baked into listing price
- **SKU format**: `DC-{8 uppercase hex}`
- **Pricing cascade**: ISBN → MPN → keywords → research → Gemini grounding → AI estimate

### Critical Gotchas
- `.env` not in git — `load_dotenv_manually()` walks parent dirs (supports worktrees)
- eBay templates use **inline styles only** (eBay strips `<style>` on mobile)
- `ebay_aspect_schema` (not old `ebay_required_aspects`) — old key is stale
- Queue routes at `/api/start`, `/api/pause`, `/api/skip` (no `/queue/` prefix)
- System routes at `/api/system/health`, `/api/system/restart`
- Browse API uses **client credentials** (different auth from user token)
- `rembg` downloads ~170MB ONNX model on first run
- Windows cp1252 can't encode emojis in logs — cosmetic only, doesn't crash pipeline

## Dependencies

### External
- **Flask 3.1** — Web framework with app factory + blueprints
- **Google Gemini** (google-genai 1.64) — Vision analysis + Google Search grounding
- **SQLAlchemy 2.0** — ORM with SQLite WAL mode
- **Flask-SocketIO + Eventlet** — Real-time WebSocket communication
- **React 18 + Vite 7** — Frontend framework and build tool
- **Zustand 5** — State management (single store pattern)
- **Tailwind CSS 4 + shadcn/Radix UI** — Styling and component primitives
- **rembg + Pillow** — AI background removal + image processing
- **@dnd-kit** — Drag-and-drop image reordering

### Ports
- Production: Flask on **5000** (API + React SPA at `/app/`)
- Dev: Vite on **5175** proxies `/api` to `127.0.0.1:5000`

### Database
SQLite at `data/commander.db` — WAL mode, SQLAlchemy ORM
- `jobs` — 8-char hex PK, status, AI data + overrides as JSON text columns
- `templates` — Saved listing presets (name, data_json, use_count)
- `orphaned_media` — Failed upload tracking for cleanup
- `app_tokens` — eBay access token persistence
