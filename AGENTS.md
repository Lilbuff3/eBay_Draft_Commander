# eBay Draft Commander

## Purpose
AI-powered eBay listing automation platform. Flask backend + React TypeScript PWA frontend. Scans product images from an inbox folder, uses Google Gemini AI for vision analysis and research grounding, maps eBay categories and pricing, then creates listings via the eBay Trading API (AddFixedPriceItem XML). Real-time Socket.IO sync to a mobile-friendly dashboard.

### Hard Rules (no IDE hook enforces these here — discipline required)
Claude Code enforces some of these with hooks; Antigravity/Gemini has no such rails, so they are rules:
1. **Never edit `.env` directly** — use SettingsManager / the Settings UI / `/api/settings`. `.env` writes are atomic (`.tmp` + `os.replace`) and GET-masked secrets (`••••`) must never be written back.
2. **Never hand-edit `static/app/`** — it is build output. Change `frontend/src`, then `npm run build`, and commit the regenerated build with the source.
3. **Never commit `data/commander.db` from a feature branch/worktree** — a local DB riding a branch clobbers master's (happened 2026-07-17).
4. **Restart the backend after backend changes** — no hot reload: `POST http://127.0.0.1:5000/api/system/restart` (409 = running unsupervised, restart manually).
5. **Run `npx eslint` on changed frontend files** — Claude's auto-lint hook doesn't exist here.
6. **Tests need Python 3.12**: `"C:\Program Files\Python312\python.exe" -m pytest tests/unit -q` — bare `python` may be a 3.13 without deps.

### Common Patterns
- **Tab-based navigation** — `activeTab` in Zustand store, persisted to localStorage, no react-router
- **Single Zustand store** — `useCommanderStore.ts` manages jobs, queue, settings, UI state
- **Socket.IO real-time** — `job_added`, `job_update`, `job_log` events via `useJobSync` hook
- **Condition priority chain** — user_override > metadata > folder_name > AI-detected > DEFAULT
- **3-phase AI pipeline** — Phase 1: Gemini vision → Phase 2: Google Search grounding → Phase 3: aspect mapping
- **Trading API XML** for all new listings (`AddFixedPriceItem`), Inventory API for management
- **Free shipping** — `ESTIMATED_SHIPPING_COST` ($6.50) baked into listing price
- **SKU format**: `DC-{8 uppercase hex}`
- **Pricing cascade**: ISBN → MPN → keywords → research → Gemini grounding → AI estimate
